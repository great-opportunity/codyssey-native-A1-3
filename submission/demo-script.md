# 시연 대본

요구사항별로 **무엇을 보여주고 무엇을 말할지** 정리했습니다.
화면은 <https://rewind-eng-mvp.vercel.app> 와 GitHub 저장소를 오가며 진행합니다.

---

## 1. 환경 변수로 API 키를 안전하게 관리

> 가장 설명하기 좋은 부분입니다. "왜 필요한가 → 어떻게 했는가" 순서로 말합니다.

### 말할 내용

OpenAI API 키는 신용카드와 같아서, 그 키로 AI를 부르면 제 계정에서 요금이 나갑니다.
코드에 키를 그대로 적으면 GitHub에 그대로 올라가고, 공개 저장소를 훑어 키를 수집하는
봇이 있기 때문에 금방 도용됩니다.

그래서 코드에는 **값이 아니라 이름만** 적었습니다. 실제 값은 프로그램이 실행되는
환경에 두고 거기서 꺼내 쓰기 때문에 환경 변수라고 부릅니다.

### 보여줄 것 (순서대로)

**① 코드에는 이름만 있다** — `api/index.py`

```python
client = OpenAI(api_key=os.environ.get("OPENAI_API_KEY"))
```

**② 저장소 안에서 키가 어떻게 다뤄지는지** — 터미널에서

```bash
git grep -n "OPENAI_API_KEY" -- "*.py" ".env.example"
```

세 줄이 나오고, 이것이 전부입니다.

```
.env.example:1:OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxx      ← 견본(가짜)
api/index.py:256:  ...os.environ.get("OPENAI_API_KEY")...   ← 이름만
api/index.py:310:  ...os.environ.get("OPENAI_API_KEY")...   ← 이름만
```

**진짜 키는 저장소 어디에도 없습니다.**

**③ 키를 담은 파일은 올라가지 않는다** — `.gitignore` 에 `.env*` 가 있습니다.

```bash
git check-ignore -v .env
```

**④ 그럼 실제 값은 어디에?** — 두 곳에 따로 둡니다.

| 실행 위치 | 값이 있는 곳 |
| --- | --- |
| 내 노트북 | 프로젝트 폴더의 `.env` (GitHub에 안 올라감) |
| 배포된 사이트 | Vercel → Settings → **Environment Variables** |

Vercel 대시보드의 Environment Variables 화면을 열어 `OPENAI_API_KEY` 가 등록된 것을
보여줍니다. 값은 가려져 있습니다.

**⑤ 대신 견본을 올려뒀다** — `.env.example` 을 열어 보여줍니다. 다른 사람이 이
저장소를 받으면 어떤 이름의 값이 필요한지 알 수 있습니다.

### 나올 만한 질문

**"키가 없으면 어떻게 되나요?"**
→ AI 호출이 `AuthenticationError`로 실패하고, 화면에는 "서비스 설정에 문제가 있어
분석할 수 없어요"가 뜹니다. 사용자에게 키 문제라고 알리지 않는 이유는, 방문자가 할 수
있는 일이 없고 내부 사정을 드러내기 때문입니다. 자세한 원인은 서버 로그에 남습니다.

## 2. 사용자 입력을 받는 UI

**보여줄 것**: 분석하기 페이지 (<https://rewind-eng-mvp.vercel.app/analyze.html>)

입력 방식이 세 가지이고 탭으로 나뉘어 있습니다.

| 탭 | 입력 방식 |
| --- | --- |
| 텍스트 붙여넣기 | 큰 입력창에 대화 내용을 직접 붙여넣기 |
| txt 파일 업로드 | 파일 선택 |
| 녹음 파일 업로드 | m4a·mp3·wav 선택 (20분 내외) |

탭을 눌러 화면이 바뀌는 것을 보여주고, 선택한 파일 이름이 화면에 표시되는 것도
함께 보여줍니다.

## 3. AI 결과를 화면에 표시

**보여줄 것**: 아래 대화를 붙여넣고 **분석하기**. 30초 남짓 걸립니다.

```
so how was your weekend did you do anything special

yeah I go to Busan with my family it was my first time

oh nice how long did you stay there

we stay two nights the weather was very good so we can walk a lot near the beach

that sounds lovely what did you eat

we eat a lot of seafood my mother she like very much the raw fish but I am little scared about it

haha that's understandable did you try it anyway

yes I try one piece because my father said me to try it actually it was not bad
```

결과는 세 덩어리로 나옵니다.

1. **총평** — 전반적인 피드백 한두 문장
2. **반복되는 실수 패턴** — 유형 이름 + 횟수 + 다음 수업에 의식할 점
3. **문장별 피드백** — 원문 → 교정문 → 이유

> 시간이 있다면 녹음 파일로 시연하면 더 좋습니다. 화자를 `나` / `튜터`로 나눠
> 받아쓴 전체 대화와, 각 피드백에 찍힌 발화 시각(`03:30`)까지 보여줄 수 있습니다.
> 다만 20분 녹음은 4~5분이 걸리므로 시간을 확인하세요.

## 4. 실패 처리 — 세 가지 모두 구현

요구사항은 셋 중 **하나 이상**이지만 전부 구현했습니다.

### ① 빈 입력 — 즉시 시연 가능

아무것도 입력하지 않고 **분석하기**를 누릅니다.

> 분석할 텍스트를 입력해주세요.

**말할 내용**: 이건 서버에 보내기 전에 브라우저에서 막습니다. 응답이 즉시 오고,
AI를 부르지 않으니 비용도 들지 않습니다.

### ② API 오류 (4xx/5xx) — 코드로 설명

실패 원인마다 다른 상태 코드와 안내를 보냅니다. 코드를 나눈 기준은 **누구 책임인가**
입니다.

| 원인 | 코드 | 화면 메시지 |
| --- | --- | --- |
| 잔액 소진·호출 폭주 | `429` | 지금은 요청이 밀려 있어요. 잠시 후 다시 시도해주세요. |
| API 키가 틀림 | `500` | 서비스 설정에 문제가 있어 분석할 수 없어요. |
| OpenAI 장애 | `502` | AI 서버에 일시적인 문제가 있어요. |
| 제한 시간 초과 | `504` | 분석이 제한 시간 안에 끝나지 않았어요. |

터미널에서 잘못된 요청을 직접 보내 보일 수도 있습니다.

```bash
curl -X POST https://rewind-eng-mvp.vercel.app/api -d 'not json'
```

> `{"error": "요청 형식이 올바르지 않습니다."}` — HTTP 400

**말할 내용**: 처음에는 모든 실패를 `502` 하나로 묶었는데, 그러면 잔액이 떨어진
것인지 키가 틀린 것인지 구분할 수 없었습니다. 원인마다 사용자가 할 일이 다르므로
나눴습니다. 키가 틀린 건 OpenAI 잘못이 아니라 제 설정 문제라서 `502`가 아니라
`500`으로 답합니다.

### ③ 지연·타임아웃 — 녹음 시연 중에 자연스럽게

녹음을 올리면 진행 상황이 계속 표시됩니다.

```
화자 나눠서 받아쓰는 중 3/6  142초 · 20분 녹음은 5분 안팎 걸려요
```

**말할 내용**: 20분 녹음은 4~5분이 걸립니다. 아무 표시가 없으면 고장으로 오해하기
때문에 단계와 경과 시간을 계속 보여줍니다. 제한 시간을 넘기면 요청을 중단하고
다시 시도하도록 안내합니다.

여유가 있다면 **제한 시간을 세 겹으로 둔 이유**까지 설명하면 좋습니다.

```
브라우저가 포기        320초
Vercel 함수 강제 종료   300초
OpenAI 호출 포기       250초   ← 가장 먼저
```

안쪽이 먼저 포기해야 바깥이 결과를 받을 수 있습니다. 개발 중 이 순서가 반대여서
6개 조각 중 5개를 마친 작업을 통째로 잃은 적이 있어 바로잡았습니다.
